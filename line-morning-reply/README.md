# 教師離線權 × LINE 早晨預約回覆

## 每天怎麼用
1. **晚上想看時**，用手機打開 Google 試算表的「收件匣」，就能看到家長傳的訊息（你不必開 LINE）。
2. 在「我的回覆」欄打好回覆內容。
3. 隔天要發的班級通知，寫在「公告」分頁（對象填「全部」或群組 ID）。
4. **上學日早上 7:30** 系統會自動送出，狀態欄會變成「已發送」。
5. 16:00 後傳私訊的家長，會收到一次自動回覆：「老師明早 7:30 回覆，緊急請打學校電話」。

## 一次性設定（約 20 分鐘）
1. **建立 LINE 官方帳號**（LINE Official Account Manager，免費）→ 設定 → Messaging API → 啟用。
2. 到 **LINE Developers** → 你的 Channel → Messaging API 分頁 → 產生 **Channel access token（long-lived）**，先複製下來。
3. 官方帳號「回應設定」：**關閉**「自動回應訊息」、**開啟** Webhook；要放進班群的話，也要開啟「允許加入群組」。
4. 新增一份 Google 試算表 → 擴充功能 → Apps Script → 貼上 `Code.gs` 全部內容。
5. Apps Script 左側「專案設定」：
   - 時區設為 **(GMT+08:00) 台北**
   - 「指令碼屬性」新增 `LINE_TOKEN` = 第 2 步複製的 token
6. 修改程式最上方的 `SCHOOL_PHONE`、自動回覆文字 → 選 `setup` → 執行（第一次會要你授權）。
7. 部署 → 新增部署 → 網頁應用程式：執行身分「我」、存取權「所有人」→ 複製網址。
8. 回到 LINE Developers 把網址貼到 **Webhook URL**，開啟 Use webhook。（如果按 Verify 顯示錯誤，先實際傳一則訊息測試，通常還是能收到。）
9. 請家長加官方帳號好友，或把官方帳號邀請進班級群組。

## 注意事項
- **個人 LINE 帳號沒辦法自動化**（LINE 沒有開放 API），一定要用官方帳號。
- **免費方案每月只有 200 則推播**。推播到群組時，**每位群組成員各算 1 則**（30 人的班群發 1 次＝30 則）。私訊回覆比較省額度，自動回覆則不算額度。
- 週末不會發送。國定假日或寒暑假想暫停，到 Apps Script「觸發條件」把 `scheduleToday` 先停用就好。
- 試算表裡有學生和家長的資料，**不要共用**給別人。
